# SGV — Sistema de Gestão de Vendas

Sistema web de gestão comercial desenvolvido como projeto acadêmico e técnico.

## Stack

### Frontend
- React
- TypeScript
- Vite
- Bootstrap 5

### Backend
- NestJS
- TypeScript
- Prisma

### Banco de Dados
- MySQL 8

### Infraestrutura
- Docker
- Docker Compose
- Traefik

## Estrutura

- `backend/` — API e regras de negócio
- `frontend/` — interface da aplicação
- `prisma/` — schema e migrations
- `docker/` — arquivos relacionados à infraestrutura
- `docs/` — documentação do projeto
